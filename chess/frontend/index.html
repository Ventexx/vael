Connect your browser board

Lichess or Chess.com. Your choice of pieces and board.

  1. Add the companion extension

    Zen / Firefox: enter about:debugging#/runtime/this-firefox in the browser address bar. Choose Load Temporary Add-on… and select manifest.json inside the folder below. Load it again after restarting your browser.

    Chrome / Edge: open Extensions → Manage extensions. Enable Developer mode, choose Load unpacked, and select this folder. If already installed, click its Reload button after an update.

  2. Open the game you want to mirror

    On Lichess, keep the game's move list available. Click the Vael Chess Live extension in that tab.

  3. Pair with this workspace

    Paste this code into the extension and choose Connect to Vael. If asked, allow access to 127.0.0.1 — that is Vael on your own computer.

Pair once. The selected game reconnects after tab refreshes and app restarts. Allow chess-site access in the extension for automatic reconnection. Use Switch browser/tab in Live to pair a different browser.
